# CODE AUDITOR v1.0 [PRO VERSION]

---

## 📖 Описание системы

**CODE AUDITOR** — это высокопроизводительный программный комплекс для глубокого анализа исходного кода.  
Система совмещает классическую проверку стандартов **W3C** с экспертным анализом на базе нейросетевых алгоритмов **Gemini AI**.

---

## ⚙️ Основные характеристики

- **Архитектура:** модульная (plugin-based) с изоляцией ошибок  
- **Интеллект:** использование Gemini AI для поиска логических багов и XSS  
- **Стандарты:** полная поддержка W3C API для HTML и CSS  
- **Защита:** автоматическое сохранение состояния (State Persistence)  
- **Контроль:** гибкая фильтрация типов файлов через конфигурацию  

---

## 💻 Технические требования

- **Операционная система:** любая с поддержкой Python 3.9+  
- **Библиотеки:** `google-genai`, `requests`, `python-dotenv`  
- **Сеть:** доступ к портам 80/443 для работы с API  

---

## 🛠 Пример файла конфигурации (.env)

Создайте файл `.env` в корневом каталоге со следующим содержимым:

```env
GEMINI_API_KEY=AIzaSyA...   # Ваш ключ из Google AI Studio
GEMINI_MODEL=models/gemini-2.0-flash
SOURCE_DIR=src
ENABLE_W3C=True
ENABLE_GEMINI=True
CHECK_HYPERTEXT=True
CHECK_STYLES=True
CHECK_SCRIPTS=True
API_SLEEP=7_15

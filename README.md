[ОПИСАНИЕ СИСТЕМЫ]
------------------
CODE AUDITOR — это высокопроизводительный программный комплекс для глубокого 
[cite_start]анализа исходного кода[cite: 1]. Система совмещает классическую проверку 
[cite_start]стандартов W3C с экспертным анализом на базе алгоритмов Gemini AI[cite: 1].

[ОСНОВНЫЕ ХАРАКТЕРИСТИКИ]
-------------------------
* [cite_start]АРХИТЕКТУРА: Модульная (Plugin-based) с изоляцией ошибок[cite: 1].
* [cite_start]ИНТЕЛЛЕКТ: Использование Gemini AI для поиска багов и XSS[cite: 1].
* [cite_start]СТАНДАРТЫ: Полная поддержка W3C API для HTML и CSS[cite: 1].
* [cite_start]ЗАЩИТА: Автоматическое сохранение состояния (Persistence)[cite: 1].
* [cite_start]КОНТРОЛЬ: Гибкая фильтрация типов файлов через .ENV[cite: 1].

[ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ]
------------------------
* [cite_start]Операционная система: Любая с поддержкой Python 3.9+[cite: 1].
* [cite_start]Библиотеки: google-genai, requests, python-dotenv[cite: 1].
* [cite_start]Сеть: Требуется доступ к портам 80/443 для работы с API[cite: 1].

[ПРИМЕР ФАЙЛА КОНФИГУРАЦИИ (.ENV)]
----------------------------------
Создайте файл .ENV со следующим содержимым:

GEMINI_API_KEY=YOUR_KEY_HERE
GEMINI_MODEL=models/gemini-2.0-flash
SOURCE_DIR=src
ENABLE_W3C=True
ENABLE_GEMINI=True
CHECK_HYPERTEXT=True
CHECK_STYLES=True
CHECK_SCRIPTS=True
API_SLEEP=7_15

[ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ]
-----------------------------
1. [cite_start]ПОДГОТОВКА: Разместите код в папке, указанной в SOURCE_DIR[cite: 1].
2. [cite_start]ЗАПУСК: Выполните команду "PYTHON CODE_AUDITOR.PY"[cite: 1].
3. [cite_start]ПРОЦЕСС: Прогресс сохраняется в AUDIT_STATE.TEMP.JSON[cite: 1].
4. [cite_start]ПАУЗА: Система делает паузу (API_SLEEP) для обхода лимитов[cite: 1].
5. [cite_start]РЕЗУЛЬТАТ: Проверьте файл CODE_AUDITOR_REPORT.HTML[cite: 1].

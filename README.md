1. ОБЗОР СИСТЕМЫ (NEW VERSION)

Code Auditor Pro — это обновленная интеллектуальная экосистема для глубокого аудита исходного кода. В новой версии реализована трехуровневая модель верификации, объединяющая классические веб-стандарты и мощь двух конкурирующих нейросетей: Google Gemini и xAI Grok.

Система предназначена для работы в высоконагруженных проектах, где цена ошибки в логике или безопасности критически высока. Инструмент автоматически масштабирует глубину проверки в зависимости от типа файла и доступности API-ресурсов.

Что нового в этой версии:

Интеграция xAI Grok (Dual Mode): Модуль Grok теперь выступает одновременно и как логический аудитор, и как эмулятор строгих стандартов (W3C/ESLint).

Улучшенная матрица покрытия: Каждый файл теперь содержит «бейджи» инструментов, которые его реально проверили.

Dynamic Rate Limiting: Поддержка рандомизированных пауз (min_max) для обхода самых жестких анти-спам фильтров.

Корпоративный UI-отчет: Полностью переработанный визуальный стиль с группировкой по критичности и наглядной статистикой «здоровья» проекта.

2. МАТРИЦА ОТВЕТСТВЕННОСТИ И ИНСТРУМЕНТЫ

Система распределяет задачи между модулями для достижения максимальной точности:

HTML/CSS: Тройной контроль — W3C Validator (стандарты), Gemini AI (архитектура), Grok Dual (синтаксис и доступность).

SCSS/SASS: Интеллектуальный анализ вложенности, переменных и миксинов через Gemini и Grok.

JS/TS/React: Глубокий аудит логики, хуков, предотвращение XSS-уязвимостей и утечек памяти.

Backend (Py/PHP): (Новое!) Экспериментальная поддержка анализа серверной логики через модуль Grok.

Статусы покрытия (Coverage):

Clean: Файл успешно прошел проверку всеми активными модулями, замечаний нет.

Dirty: Обнаружены проблемы. Файл снабжен списком найденных багов с указанием строк.

Not Checked: Файл пропущен (например, если API-ключи не настроены или лимиты запросов исчерпаны).

3. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ И КОНФИГУРАЦИЯ

Среда: Python 3.9+

Зависимости: google-genai, requests, python-dotenv.

Ключевые переменные окружения (.env):

GEMINI_API_KEY: Ключ для доступа к моделям серии Gemini 2.0/3.0.

XAI_API_KEY: Ключ для доступа к Grok.

API_SLEEP: Поддерживает формат 15_30 (случайная пауза от 15 до 30 секунд для защиты от банов).

GEMINI_MAX_CHARS / GROK_MAX_CHARS: Лимиты на объем передаваемого кода (авто-обрезка для экономии токенов).

RESUME_AUDIT: При значении True скрипт продолжит работу после сбоя или остановки, используя файл audit_state.temp.json.

4. ПОРЯДОК ЭКСПЛУАТАЦИИ

ШАГ 1: Развертывание Установите библиотеки: pip install google-genai requests python-dotenv

ШАГ 2: Настройка пресетов В блоке конфигурации выберите активные модели. Вы можете комбинировать Gemini и Grok для получения «второго мнения» по сложным участкам кода.

ШАГ 3: Запуск процесса python code_auditor.py

Система выведет в консоль текущую конфигурацию и визуальную шкалу прогресса с индикацией активных модулей для каждого файла.

ШАГ 4: Обработка результатов Откройте code_auditor_report.html.

Используйте фильтрацию по Severity (Error/Warning/Suggestion).

Обратите внимание на блок Suggestion: там часто содержатся готовые фрагменты кода для исправления (Refactoring Snippets).

5. КЛАССИФИКАЦИЯ ИНЦИДЕНТОВ

🔴 ERROR (Критический): Прямые ошибки синтаксиса, неработающие ссылки в HTML или критические дыры в безопасности JS.

🟡 WARNING (Средний): Избыточность кода, нарушение принципов DRY, потенциальные проблемы с производительностью на мобильных устройствах.

🔵 SUGGESTION (Рекомендация): Советы по улучшению читаемости, использованию новых стандартов языка или оптимизации структуры папок.

```
.env example:
# ==============================================================================
# КОНФИГУРАЦИЯ CODE AUDITOR PRO
# ==============================================================================

# --- GEMINI AI (Google) ---
# Ключ переименован для соответствия новой логике gemini_key
GEMINI_API_KEY=
GEMINI_MODEL=models/gemini-2.0-flash
GEMINI_MAX_CHARS=45000

# --- GROK AI (xAI) ---
XAI_API_KEY=
GROK_MODEL=grok-2-latest
GROK_MAX_CHARS=45000

# --- ГЛОБАЛЬНЫЕ ВКЛЮЧАТЕЛИ ---
ENABLE_W3C=False
ENABLE_GEMINI=True
ENABLE_GROK=True

# --- НАСТРОЙКИ СКОРОСТИ И ПАУЗ ---
# ВАЖНО: Уменьшено с 30 до 2 секунд, чтобы убрать "зависание" между файлами
API_SLEEP=2

# --- ПУТИ И ФИЛЬТРЫ ---
SOURCE_DIR=src
CHECK_HYPERTEXT=True
CHECK_STYLES=True
CHECK_SCRIPTS=True

# --- СОСТОЯНИЕ ---
RESUME_AUDIT=True
TEMP_STATE_FILE=audit_state.temp.json
```

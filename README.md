Code Auditor Pro представляет собой централизованную систему автоматизированного аудита исходного кода, предназначенную для обеспечения стандартов качества и безопасности в корпоративных проектах. Система использует гибридный метод анализа, сочетающий строгую валидацию спецификаций W3C и предиктивный анализ на базе искусственного интеллекта Gemini AI.

Инструмент ориентирован на минимизацию рисков при развертывании (deployment) и оптимизацию процесса Code Review.

Этот скрипт представляет собой автоматизированную систему аудита кода, которая сочетает в себе проверку на соответствие мировым стандартам и интеллектуальный анализ с помощью нейросетей.

Вот что именно он делает:


Сканирует проект и фильтрует файлы: скрипт обходит указанную директорию (src) и выбирает для проверки файлы популярных форматов: HTML, CSS (включая SCSS/SASS) и JavaScript (включая TypeScript и React).

Проводит двойную проверку качества:


W3C Валидация: отправляет HTML и CSS код на официальный сервис W3C для проверки на синтаксические ошибки и соответствие веб-стандартам.


AI-анализ (Gemini): использует нейросеть для поиска логических багов, уязвимостей (например, XSS), потенциальных утечек памяти и оценки чистоты кода (DRY, именование).


Управляет нагрузкой на API: для предотвращения блокировок со стороны сервисов скрипт делает настраиваемые паузы между проверками файлов и может обрезать слишком длинные файлы перед отправкой в AI.

Обеспечивает отказоустойчивость и продолжение работы:

Если проверка одного файла упадет с ошибкой, скрипт не остановится и продолжит работу дальше.

Система сохраняет промежуточный прогресс в файл. Если аудит прервется, его можно возобновить с того же места, не переделывая уже выполненную работу.

Формирует наглядную отчетность: по итогам работы генерирует профессиональный HTML-отчет с цветовой индикацией (Clean/Dirty), статистикой и конкретными советами по исправлению найденных проблем.

2. КЛЮЧЕВОЙ ФУНКЦИОНАЛ
============================================================
```

Матрица ответственности:

HTML/CSS: Двойная проверка через W3C Nu Validator и Gemini AI.

SCSS/SASS/Less: Интеллектуальный анализ архитектуры стилей.

JS/TS/React: Глубокий аудит логики, безопасности (XSS/инъекции) и производительности.

Отказоустойчивость и Изоляция: Сбой одного модуля или сетевая ошибка при обращении к внешним API не прерывает общий процесс аудита. Система изолирует проблемный участок и продолжает работу.

Состояние и Преемственность (State Persistence): Поддержка механизма "Resume". В случае принудительной остановки аудит возобновляется с точки разрыва, исключая повторную тарификацию API-запросов и экономя время.

Прозрачность покрытия (Coverage Tracking): Система четко классифицирует файлы по трем статусам:

Clean: Проверка пройдена, замечаний нет.

Dirty: Обнаружены отклонения от стандартов.

Not Checked: Файл пропущен из-за отсутствия подходящих валидаторов.

Корпоративная отчетность: Генерация детализированного HTML-отчета с визуализацией серьезности ошибок (Error, Warning, Suggestion) и готовыми рекомендациями по исправлению кода.

4. ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ И ИСПОЛЬЗОВАНИЮ
============================================================
```
ШАГ 1: Подготовка окружения Установите необходимые пакеты командой: pip install google-genai requests python-dotenv

ШАГ 2: Конфигурация системы Настройте параметры в файле .env или непосредственно в блоке конфигурации скрипта:

GEMINI_API_KEY: Ваш корпоративный ключ доступа.

SOURCE_DIR: Путь к директории с исходным кодом (по умолчанию 'src').

API_SLEEP: Интервал между запросами (поддерживает диапазон, например '7_15', для обхода лимитов).

ШАГ 3: Запуск аудита Выполните запуск из терминала: python code_auditor.py

ШАГ 4: Мониторинг в реальном времени В процессе работы консоль отображает прогресс выполнения: [idx/total] Имя_файла... Статус [Активные модули]

ШАГ 5: Анализ результатов По завершении процесса в корневой директории будет сформирован файл: code_auditor_report.html Откройте его в любом браузере для детального ознакомления с результатами аудита.
